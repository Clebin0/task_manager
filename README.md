Projeto de estudo em Kotlin criado para consolidar fundamentos de backend, orientação a objetos e persistência de dados.

## Funcionalidades

- criação de tarefas;
- listagem de registros;
- atualização de status;
- persistência local;
- validação de entradas;
- interface por terminal.

## Conceitos praticados

- classes e data classes;
- encapsulamento;
- CRUD;
- SQL via JDBC;
- controle de fluxo;
- tratamento de entrada;
- organização de responsabilidades.

## Executar

Requisitos: JDK 21 e Gradle 8.14 ou superior.

```bash
gradle run
```

O Gradle instala o driver SQLite JDBC. A aplicação cria a tabela `Tarefas` automaticamente no arquivo local `banco_tarefas.db`.

## Objetivo

Este repositório representa uma etapa de estudo dos fundamentos que sustentam projetos maiores de backend e automação.
